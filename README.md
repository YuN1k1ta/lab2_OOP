## Цель работы. Научиться использовать композицию, агрегацию, наследование, абстрактные классы, интерфейсы и полиморфизм при проектировании классов.



## Описание задания



Реализация системы работы с медиаэлементами на языке **C#**:



1. **`Track`** — класс-сущность (трек)

2. **`Playlist`** — класс-контейнер (плейлист)

3. **`MediaItem`** — абстрактный базовый класс

4. **`Podcast`** — подкаст

5. **`Audiobook`** — аудиокнига

6. **`SelectionRule`** — интерфейс выбора треков



## Постановка задачи



### Класс `Track` (трек)



Трек наследуется от абстрактного класса `MediaItem`.



**Поля:**



- `number` — номер трека (`int`)

- `title` — название (`string`)

- `artist` — исполнитель (`string`)

- `duration` — объект `Duration`

- `genres` — массив жанров (`string\[]`)

- `Plays` — количество прослушиваний



**Правила:**



- Длительность от 1 до 3600 секунд

- Название не может быть пустым

- Исполнитель не может быть пустым

- Количество прослушиваний может только увеличиваться

- Массив жанров защищён от внешнего изменения



### Класс `Duration`



Класс используется для хранения длительности трека.



**Правила:**



- Минимальная длительность — 1 секунда

- Максимальная длительность — 3600 секунд

- Значение хранится внутри объекта `Duration`



### Класс `Playlist` (плейлист)



Плейлист агрегирует объекты `Track`.



**Поля:**



- `tracks` — массив треков (`Track[]`)

- `count` — количество треков



**Операции:**



- `Add(track)` — добавить трек

- `RemoveByNumber(number)` — удалить трек по номеру

- `GetTracks()` — получить копию массива треков

- `GetTotalDuration()` — получить общую длительность

- `GetMostPopular()` — получить самый популярный трек

- `SortByPlays()` — сортировка по количеству прослушиваний



Плейлист хранит ссылки на существующие объекты `Track`. Удаление плейлиста не удаляет сами треки из библиотеки.



## Реализованные требования



### Задание 1. Агрегация и композиция



-  `Playlist` агрегирует объекты `Track`

-  Треки существуют независимо от плейлиста

-  Удаление трека из плейлиста не удаляет объект `Track`

-  `Track` содержит объект `Duration`

-  `Duration` создаётся внутри `Track`

-  `Duration` используется как часть объекта `Track`



### Задание 2. Абстрактный класс и наследование



-  Создан абстрактный класс `MediaItem`

-  `MediaItem` содержит общее состояние медиаэлементов

-  Реализован общий учёт прослушиваний

-  Определён абстрактный метод `Play()`

-  `Track` наследуется от `MediaItem`

-  `Podcast` наследуется от `MediaItem`

-  `Audiobook` наследуется от `MediaItem`

-  Наследники вызывают конструктор базового класса

-  Каждый наследник имеет собственную реализацию `Play()`



### Задание 3. Интерфейс



-  Создан интерфейс `SelectionRule`

-  Определена операция `Select(Track[] tracks)`

-  `OrderSelectionRule` — выбор треков по исходному порядку

-  `PopularitySelectionRule` — выбор по количеству прослушиваний

-  `RandomSelectionRule` — случайный выбор без повторов

-  Клиентский код работает через интерфейс `SelectionRule`

-  Разные реализации обрабатываются одинаковым способом



### Задание 4. Композиция вместо наследования



Для представления дополнительных характеристик медиаэлемента используются отдельные классы:



-  `MediaCarrier` — носитель

-  `AccessLevel` — уровень доступа

-  `AgeRating` — возрастная маркировка

-  `PremiumMediaItem` — медиаэлемент, содержащий эти компоненты



Структура композиции:



PremiumMediaItem

&#x20;├── MediaCarrier

&#x20;├── AccessLevel

&#x20;└── AgeRating

Дополнительные характеристики представлены через композицию, а не через создание отдельных классов для каждой комбинации.



### Задание 5. Возможность расширения



-  Новая разновидность медиаэлемента может быть добавлена новым классом

-  Новый класс может наследоваться от `MediaItem`

-  Новый класс реализует собственный `Play()`

-  Существующие классы изменять не требуется

-  Общая работа с объектами выполняется через базовый тип `MediaItem`



## Полиморфизм



-  Используется массив типа `MediaItem[]`

-  В массив помещаются объекты `Track`, `Podcast`, `Audiobook`

-  Все объекты обрабатываются через базовый тип `MediaItem`

-  Для воспроизведения вызывается `Play()`

-  Каждый класс имеет собственную реализацию `Play()`

-  Тип конкретного объекта не проверяется через `is` или `switch`



## Работа с жанрами



-  В `Track` используется массив жанров `string[]`

-  При передаче массива в конструктор создаётся его копия

-  `GetGenres()` возвращает копию внутреннего массива

-  Внешний код не может напрямую изменить массив жанров
